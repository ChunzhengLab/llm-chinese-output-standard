# 大模型人机沟通规范

本仓库收录“大模型人机沟通”系列项目建议稿及其起草材料。该系列不属于国家标准、行业标准或团体标准；采用方应结合适用的法律法规、行业规范、安全规则和组织制度使用。

当前版本：V1.9，2026-09-05。

## 文件

- [第 1 部分：汉语输出规范](LLM-CN_1-2026_大模型人机沟通_第1部分_汉语输出规范.md)：规范汉字、用词、语法、语体、篇章、日常交流、技术性内容交流、标点和格式。
- [第 2 部分：交互与信息完整性规范](LLM-CN_2-2026_大模型人机沟通_第2部分_交互与信息完整性规范.md)：规范上下文使用、假设与澄清、完成状态、事实和推断区分、来源、不确定性、风险、拒绝和纠错。
- [大模型中文沟通 Skill](skills/llm-chinese-communication/SKILL.md)：将两部分规范转为用于撰写、改写、审校和回应中文内容的可执行指令。

第 1 部分规定语言表达和信息组织；第 2 部分规定交互和信息处理。技术问答、讨论或操作指导等混合内容，可分别适用两部分的相关条款。
