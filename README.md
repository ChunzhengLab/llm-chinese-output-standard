# 大模型人机沟通规范

本仓库发布“大模型人机沟通”系列项目建议稿，以及说明和许可声明；不收录起草时参考的第三方材料。该系列不属于国家标准、行业标准或团体标准；采用方应结合适用的法律法规、行业规范、安全规则和组织制度使用。

## 文件

- [第1部分：汉语输出规范](LLM-CN_1-2026_大模型人机沟通_第1部分_汉语输出规范.md)：规范汉字、用词、语法、语体、篇章、日常交流、技术性内容交流、标点和格式。
- [第2部分：交互与信息完整性规范](LLM-CN_2-2026_大模型人机沟通_第2部分_交互与信息完整性规范.md)：规范上下文使用、假设与澄清、完成状态、事实和推断区分、来源、不确定性、风险、拒绝和纠错。

第1部分规定语言表达和信息组织；第2部分规定交互和信息处理。技术问答、讨论或操作指导等混合内容，可分别适用两部分的相关条款。

## 如何使用

- **系统提示（system prompt）或模型规范**：将相关条款纳入系统提示、组织规范或模型行为要求；应按具体场景选用，不宜把全文机械拼入提示。
- **人工写作与审校**：以第1部分检查汉语表达、语体和信息结构；以第2部分检查事实边界、完成状态、来源和风险提示。
- **评测量表（rubric）**：将条款转化为与任务相关的判定项，并分别评价语言表达与交互、信息完整性。
